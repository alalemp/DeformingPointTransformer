## 后续对照实验提案（诊断后再确认细节）

1. 先根据诊断判断是否需要修正评估流程，再固定统一的验证与测试协议。
2. 保留仅 CD 的基线；候选方法为 L = L_CD + lambda_V * L_volume。
3. 每块肌肉分别计算相对体积误差平方并平均；真实体积来自训练样本 subjects.csv 的 *_mesh_ml。
4. 以 PyTorch 将模板点位移插值至模板网格，再用闭合三角网格公式计算可微体积；现有 NumPy 评估不能直接反向传播。
5. 正确处理模型输入模板中的随机噪声，避免把输入抖动误记为模型形变。
6. 在独立小例子上检查零位移体积、已知统一缩放（体积随尺度三次方变化）、梯度有限和方向合理、毫米/毫升单位及肌肉标签。
7. 保持样本划分、模板、随机种子、初始条件、batch size、学习率策略、训练预算相同；只改变体积损失项。分别保存结果，不覆盖基线。
8. lambda_V 由验证集选择，结合两项损失和梯度尺度设候选；不能只看数值直接任意取 1，也不能用测试集调参。
9. 先在少数匹配折进行比较，查看 CD、HD95、逐肌肉体积、局部形变和网格自交，再决定是否扩展两帧全部折。
10. 体积损失可能改善大小但不保证位置/形状准确；固定拓扑也不能保证形变网格无自交。
